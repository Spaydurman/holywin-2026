# Holywin landing page mockup

A single-page Holywin concept built with React, TypeScript, Motion, Anime.js, and Vite. The artwork is generated for this mockup, and the gallery images are illustrative rather than photos from a real event.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Before launch

- Replace the “Coming soon” date and venue with confirmed event details.
- Replace the illustrative gallery with approved Holywin photos.
- Connect the registration form to a backend or form service. It currently only shows a local mockup confirmation and does not send or store data.
